a bit about me

I started coding because I wanted things to work the way I wanted, not the way they were shipped. That itch never really went away.

These days I live in terminals, run Linux, and build minimal tools that ship as single binaries — mostly Kotlin/JVM, Rust and Go. Frameworks stacked on frameworks make me twitchy.

My signature move: rewrite the thing instead of configuring the thing. Around here, “no config file” is a compliment.

Recently I wrote an entire Android Minecraft Java launcher from scratch — Java 25 running on-device, LWJGL, a custom JNI bridge and a GLSL shim — just so one specific server pack would run on a phone. Worth it.

I also build AI-dev tooling for myself: a terminal coding agent in Rust, bridges, session managers. And sometimes I build tiny pages for people I care about.
